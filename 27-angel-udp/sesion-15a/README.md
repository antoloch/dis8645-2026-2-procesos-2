## lectura

En estas páginas se sigue trabajando con la biblioteca Turtle de Python. Sigo aprendiendo a crear diferentes figuras mediante movimientos, giros y bucles.

Primero se dibuja una línea recta y luego un paralelogramo (la base de la figura corresponde a un paralelogramo, entendido como un «cuadrilátero cuyos lados opuestos son paralelos entre sí» [Real Academia Española (RAE), s. f.]) que, al repetirse varias veces y cambiar su ángulo, acaba creando una figura parecida a un copo de nieve.

También se explica cómo cambiar el color del fondo y de las líneas, además de utilizar la biblioteca random para elegir colores al azar desde una lista.

Es como jugar un *gambling* (al azar) de resultados cada vez que se ejecuta el programa, sin tener que cambiar los colores manualmente.

Adelante, se enseñan nuevas instrucciones que dejan mover la tortuga sin dibujar. También se explica cómo crear funciones para agrupar y reutilizar instrucciones, la importancia de dejar correctamente los espacios dentro del código y cómo utilizar comentarios para explicar o desactivar líneas específicas.

Por último pág 109, se presenta un nuevo proyecto llamado «Diferencias espantosas», en el que se comienza a utilizar Pygame, una biblioteca de Python que deja trabajar con imágenes y sonidos para crear videojuegos.

En este caso, se busca crear un juego de diferencias que esconde una sorpresa para asustar al jugador.
