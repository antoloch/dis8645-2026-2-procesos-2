## lectura

Se utilizan diferentes herramientas de Scratch 3 para crear proyectos interactivos.

Primero, se vio como calcular el tiempo de reacción de una persona usando un cronómetro y cómo convertir ese tiempo en la distancia que recorre la Estación Espacial Internacional.

Después, se trabaja en un proyecto llamado Natación sincronizada, donde se aprende a cambiar el fondo del escenario, seleccionar personajes, duplicar sus disfraces y modificar su orientación para que sus movimientos se vieran más reales.

Finalmente, se ve como programar las flechas del teclado para controlar los movimientos del personaje, hacerlo girar, avanzar y retroceder. También se utiliza la bandera verde para establecer su posición inicial.

Esta sesión me enseñó a comprender mejor cómo combinar bloques de programación para crear animaciones y controlar personajes de manera sencilla.
