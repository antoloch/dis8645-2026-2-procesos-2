## lectura

A pesar de ser la entrega de proyecto intente leer algún capítulo igualmente, es por ello que llegue a "_Manchester Baby – The first electronic stored-program computer_"

No voy a mentir, no entendí muchas cosas por tener la mente en otras cosas, pero intenté hacer un listado de conceptos claves para re-leer el capítulo nuevamente y comprender mejor

- SSEM: de _Small-Scale Experimental Machine_, el nombre oficial de nuestro bebe Manchester xd
- Stored-program computer: en español "_computadora de programa almacenado_", es un tipo de estructura que permite cambiar las instrucciones a máquinas sin tener que cambiar piezas, es decir cambios de software y no hardware (es como el cambio de máquinas electrónicas a computaciones)
- Tubo Williams-Kilburn: es el inicio de la RAM, almacena bits. Esta basada en los tubos de rayos catodicos, la base de los televisores ""_potones_"" (CRT)
- RAM: de _Random Access Memory_. Termino que creía entender, pero que significa que la memoria puede leer y escribir datos sin necesidad de seguir una secuencia, como puede ser leer un CD o una cinta de cassette por ejemplo
- Regeneration: en español _refresco de memoria_, es el proceso donde se lee y reescriben los puntos de un tubo CRT para evitar que los bits desaparecieran
