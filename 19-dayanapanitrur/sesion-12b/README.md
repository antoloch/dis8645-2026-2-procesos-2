Uno de los referentes que encontré para comenzar a preparar nuestro proyecto 03 es el Microcosm de Hologram Electronics

es un looper, y tiene una función de glitch, algo que nos sirve quizás para revisar y hacer que el sonido se "desintegre" que es un poco la premisa que estábamos buscando

encontré un video que integra un microcosm y un oscilador, de teenage engeenering el cual incluye una pantalla (que es otra cosa que en algún momento habíamos pensado en integrar, aún no definido) muestra de forma gráfica con unas bolitas que chocan en las paredes de una figura geométrica

y mezclando ambas ideas, si se quiere demostrar de manera visual como se "destruye" el sonido podría hacerse muy de esta manera, mostrando cosas como ej: estas bolitas entre más sonidos integres más se van a difuminar o por ej las lineas de la figura se empiezan a deformar / cortar / etc.
