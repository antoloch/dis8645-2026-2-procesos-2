# sesion-11a

## apuntes sesión

Hoy seguimos trabajando en TRAZO y en la colaboración con el Grupo 1. Las dos perillas de nuestro proyecto sirven para mover el cursor en X e Y, pero el otro grupo necesitaba que una de las suyas recorriera cinco sonidos y volviera al primero después del último. Me sirvió ver que el mismo gesto, girar una perilla, puede significar dos cosas bien distintas según lo que uno quiera hacer. Terminamos reuniendo las dos formas de lectura en la clase Perilla, que se configura distinto según si usamos un potenciómetro o un encoder.

La Nati Pilar también empezó el diagrama de flujo. Separamos dos recorridos que al principio estaban juntos: lo que hace la persona al usar TRAZO y lo que tiene que hacer el programa para responderle. Por ejemplo, para la persona es «giro la perilla y se mueve el cursor», pero por dentro hay que leer un valor, convertirlo a una coordenada y decidir si ese movimiento deja una línea.
