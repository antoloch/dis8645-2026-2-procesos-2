### Interfaz efectos 

1. Encender el dispositivo.
   Todas las luces LED comienzan apagadas.

2. Presionar uno de los 9 botones para elegir un efecto.

3. La luz LED correspondiente comienza a parpadear.
   Esto indica que el efecto está seleccionado y se puede modificar.

4. Girar la perilla correspondiente al grupo del efecto.
   La perilla permite ajustar el efecto seleccionado.

5. Presionar nuevamente el mismo botón para confirmar.
   La luz LED deja de parpadear y queda encendida de forma fija.

6. Si se selecciona otro efecto:
   La luz anterior queda fija y la nueva comienza a parpadear.

7. Repetir el proceso para seleccionar y modificar otros efectos.
