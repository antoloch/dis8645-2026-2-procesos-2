# sesion-13a

## apuntes sesión

### Lo que queremos

- Explorar cómo el sonido puede reemplazar a otros estímulos sensoriales.
- Reconocimiento de sonidos.
- Memorias orales.
- Sonido, distorsión y transformación.
- Asignar una carga cultural a los sonidos.
- Explorar cómo los sonidos están ligados a las emociones.
- El sonido como herramienta para comprender el mundo desde la infancia.
- Sonido acompañado de elementos visuales.
- El sonido como invitación a descubrir una experiencia visual.
- Interactividad.
- Salida de audio externa.
- Parlante pequeño.

### Lo que no queremos

- Incorporar un micrófono.
- Alejarnos del juego o videojuego como concepto.
- Que tenga dimensiones grandes.
- Que pueda explotar.
- Generar sonidos molestos.
- Que funcione como un instrumento tradicional.
- Utilizar una carcasa de madera.
- Gastar plata.
- Que requiera un manual de instrucciones.
- Que esté limitado a un solo contexto.
- Incorporar un parlante interno de gran tamaño.
